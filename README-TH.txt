วงล้อสุ่ม (แพ็กเกจติดตั้งเป็นแอป / ใช้ออฟไลน์ / แชร์ให้คนอื่น)
=====================================================================

ในโฟลเดอร์นี้
  index.html              ตัวแอปทั้งหมด
  manifest.webmanifest    ข้อมูลแอป (ชื่อ ไอคอน สี) สำหรับติดตั้งลงเครื่อง
  sw.js                   ทำให้ใช้งานออฟไลน์ได้
  icons/                  ไอคอนแอป
  fonts/                  ฟอนต์ตัวเลข/ตัวอักษรอังกฤษ (ฝังไว้ ไม่ต้องโหลดจากเน็ต)

ต้องอัปโหลดทุกไฟล์และโฟลเดอร์ขึ้นไปด้วยกัน ห้ามเปลี่ยนชื่อ


วิธีที่ 1: เปิดจากไฟล์ในเครื่องเลย (เร็วสุด)
---------------------------------------------
ดับเบิลคลิก index.html ก็ใช้ได้ทันที ไม่ต้องมีอินเทอร์เน็ต
ข้อจำกัด: ติดตั้งเป็นแอปไม่ได้ และปุ่ม "แชร์วงล้อ (ลิงก์)" จะใช้ไม่ได้
(ใช้ "สำรองข้อมูล" แล้วส่งไฟล์ให้คนอื่นแทน)


วิธีที่ 2: นำขึ้นเว็บฟรี แล้วติดตั้งเป็นแอป (แนะนำ)
----------------------------------------------------
ต้องนำขึ้นเว็บที่เป็น https ก่อน คนที่เปิดลิงก์ไม่ต้องสมัครสมาชิก

  ก) GitHub Pages (ฟรี)
     1. สมัคร github.com แล้วสร้าง repository ใหม่ (ตั้งเป็น Public)
     2. กด "Add file > Upload files" แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ลงไป กด Commit
     3. ไปที่ Settings > Pages > Source เลือก "Deploy from a branch"
        เลือก branch main และโฟลเดอร์ /(root) แล้วกด Save
     4. รอประมาณ 1-2 นาที จะได้ลิงก์รูปแบบ https://ชื่อผู้ใช้.github.io/ชื่อrepo/

  ข) Netlify Drop
     1. เข้า app.netlify.com/drop แล้วลากโฟลเดอร์นี้ทั้งโฟลเดอร์ลงไป
     2. จะได้ลิงก์ทันที (ตามที่ทราบ ถ้าไม่สมัครบัญชี เว็บอาจถูกลบเมื่อเวลาผ่านไป
        ให้ตรวจเงื่อนไขล่าสุดของบริการก่อนใช้งานจริง)

  ค) Cloudflare Pages ก็ใช้ได้ (ต้องสมัครบัญชี)


วิธีติดตั้งลงเครื่อง (ทำครั้งเดียวขณะมีอินเทอร์เน็ต)
----------------------------------------------------
  Android (Chrome)  เปิดลิงก์ > เมนู ⋮ > "ติดตั้งแอป" หรือ "เพิ่มลงหน้าจอหลัก"
                    หรือเข้า ตั้งค่า(ฟันเฟือง) > "ติดตั้งเป็นแอปบนเครื่อง"
  iPhone / iPad     เปิดลิงก์ใน Safari > ปุ่มแชร์ > "เพิ่มลงในหน้าจอโฮม"
  คอม (Chrome/Edge) กดไอคอนติดตั้งที่ช่องที่อยู่เว็บด้านขวา

หลังเปิดครั้งแรก จะมีข้อความ "พร้อมใช้งานออฟไลน์แล้ว"
ลองเปิดโหมดเครื่องบินแล้วเปิดแอปอีกครั้งเพื่อทดสอบ


การแชร์ให้คนอื่น (ไม่ต้องสมัครสมาชิก)
--------------------------------------
  - ส่งลิงก์ของเว็บให้เลย แต่ละคนจะมีรายการในเครื่องของตัวเอง
  - ตั้งค่า > "แชร์วงล้อนี้ (ลิงก์)" สร้างลิงก์ที่มีรายชื่อของวงล้อนั้นฝังอยู่
    คนที่เปิดจะเห็นข้อความถามว่าจะเพิ่มวงล้อนี้ไหม
    (รายชื่อภาษาไทยยาวๆ จะทำให้ลิงก์ยาว ถ้าแอปแชทตัดลิงก์ ให้ใช้ไฟล์สำรองแทน)
  - ตั้งค่า > "สำรองข้อมูล" ดาวน์โหลดไฟล์ .json เก็บไว้ หรือส่งให้คนอื่น
    แล้วใช้ "นำเข้าจากไฟล์สำรอง" เพื่อเพิ่มวงล้อเข้าเครื่องใหม่
  - การนำเข้าจะ "เพิ่ม" วงล้อ ไม่ทับของเดิม


เรื่องข้อมูล
------------
  - รายชื่อและการตั้งค่าเก็บในเบราว์เซอร์ของแต่ละเครื่อง ไม่ได้ส่งไปที่ใด
  - ถ้าล้างข้อมูลเบราว์เซอร์ รายชื่อจะหาย จึงควรสำรองข้อมูลเป็นระยะ
  - เปิดแอปจากลิงก์ต่างกัน (หรือต่างเบราว์เซอร์) จะเห็นรายชื่อคนละชุด
    ใช้ สำรองข้อมูล / นำเข้า เพื่อย้าย


เมื่อแก้ไขแอปแล้วนำขึ้นเว็บใหม่
-------------------------------
เปิดไฟล์ sw.js แล้วเปลี่ยนเลขในบรรทัด  const VERSION = '1';  เป็น '2', '3', ...
ไม่เช่นนั้นเครื่องที่เคยติดตั้งไว้อาจยังเห็นเวอร์ชันเก่า
(ผู้ใช้จะเห็นเวอร์ชันใหม่ในการเปิดแอปครั้งถัดไปหลังมีอินเทอร์เน็ต)


ทดสอบบนเครื่องตัวเอง (สำหรับผู้พัฒนา)
-------------------------------------
เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน  python3 -m http.server 8080
จากนั้นเปิด http://localhost:8080 (ฟีเจอร์ออฟไลน์ใช้งานได้บน localhost)
